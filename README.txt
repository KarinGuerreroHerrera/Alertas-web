ALERTA - versión web
====================
Abre index.html en Chrome/Edge/Firefox. No necesita servidor ni instalación.

Incluye:
- Inicio de sesión y registro
- Alertas
- Creación de alertas
- Vista Hoy
- Mapa/geocercas simulado
- Perfil y sincronización simulada

Nota: la versión web conserva el diseño y los flujos de la app original, pero el mapa y la sincronización son simulados porque el proyecto original tampoco contiene un backend real.
